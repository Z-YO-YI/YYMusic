增量进展：H4C1纯振幅契约完成；[H4C2a](phase_7h4c2a_volume_intent_report.md)已将生产根应用音量与引擎回报隔离。实际到期淡出仍待H4C2b，按下文取消/恢复条件接入，不将前置条件等同于整个功能完成。

来源开发总指令§26。H4B3b已接通分钟恢复，本阶段先审计根用户音量意图、引擎音量回报与命令串行化，再定义短时淡出协议，不直接在Widget计时或创建第二播放器。

临时淡出增益不能覆盖用户选择的音量，也不能让UI音量滑块跟随淡出跳动。到期仍由原唯一根调度，渐降完成后暂停；暂停完成/取消/失败/切曲/新定时/关闭路径均需撤销旧回调，恢复正确用户音量而不自动播放。用户在淡出期间调整音量或显式暂停优先，不能用旧音量覆盖新意图。

先用可控调度与FakeAudioEngine覆盖每步时序、取消、异常、慢引擎/重入和关闭排空，再验证实际所选Android/Windows backend能力；不拿方法返回成功当真实听感验收。初版淡出时长和曲线须先在ADR明确，使用既有调度/音量协议，不顺带实现响度标准化或输出设备切换。持续更新恢复/淡出边界的文档、测试和GitHub构建证据。
