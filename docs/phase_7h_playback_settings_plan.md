# Phase 7H：真实播放设置下一批计划

2026-09-13；来源为[Phase7出口审计](phase_7_exit_audit.md)。这是下一开发批的范围与风险清单，不是已经实现，也不绕过先ADR再共享API的要求。

## 7H1：睡眠定时核心（下一项可独立验证工作）

先阅读根PlaybackController串行命令、完成事件自动推进、生命周期/关闭屏障和既有时钟约定，再写ADR。复用唯一根播放器，不把Timer放进Widget或创建另一音频实例。注入可测试时钟/调度器，实现关闭、15/30/60分钟的明确截止意图；到期只暂停，不删除队列、不停止来源或强行恢复播放。重设/取消/根关闭后的旧定时不得生效，已接受命令按根时序执行；延迟回调按截止时间判断，不用每秒累加伪时钟。

“本曲结束”必须绑定准确queue entry，并在自动下一首之前生效；不能仅订阅completed后补pause，因为根可能已开始播放下一首。先补竞争测试，再决定最小根协议；不能因同TrackRef的重复条目混淆意图。切歌、重复播放、暂停/恢复、失败、取消及关闭语义先写在ADR中。若本批无法安全覆盖本曲结束，明确保留下一增量，不宣称全套睡眠选项完成。

出口：可控时钟单元测试、真实根队列/Fake音频集成测试覆盖一次性到期、重设/取消、晚回调、关闭排空、完成事件竞争及不自动恢复播放；格式/严格分析/全量测试和构建通过，再提交push/Draft。持久化与进程重启语义须明确，不擅自将过期定时跨重启重新启动。

## 7H2及后续：原生界面与其他能力

- 核心验证后，再使用Figma设计转代码技能读取已审计本地optionsOverlay/播放设置结构，复用YYDialog/BottomSheet、图标与Token；分别安排Phone/Tablet/Windows，不用WebView。
- 播放页、歌词页、底栏、Inspector的播放设置入口共用一个可撤销导航/弹层流程，支持返回焦点、遮罩、窄屏与真实失败反馈，不重建核心。
- 输出设备只展示真实平台状态或明确“不可获取”，不得使用HTML模拟设备。选择能力先核验后端与平台支持，相关系统媒体边界与Phase10对齐，记录支持矩阵。
- 无缝、标准化和自动继续偏好必须有实际后端/根行为及测试，不把假开关写入数据库作为实现。需要依赖/API变更时先审计并更新ADR/许可证材料。
- 补侧栏只读队列摘要/入口，消除当前预留文本；完成后更新Phase7出口审计，不跳过设备QA和Phase8–11。
