## 实现

- 新增pruneSequenceBefore(expectedCursor)，与既有引擎共用串行队列；旧批次、完整条目不符或已不是当前索引的请求不提交。AudioSequenceCursor.index保持批次内绝对序号，原生索引归零后通过窗口列表投影，身份不重用。
- 根使用首cursor偏移查元数据，已播前缀达到8项且没有待存储切曲时清理。追加入口限制总窗口11项，同时保持最多两项前瞻。原生当前项和后续项保留；应用队列、currentEntryId、顺序/随机策略不因内存窗口删除而改写。
- 原生只调用removeAudioSourceRange(0,currentIndex)，不pause/seek/reload/play。原始索引归零可能晚于方法回应，因此提前订阅并在方法完成后最多等待1秒；原始索引须非负、单调不增并最终为零，generation/关闭也复核。期限列表同步删除前缀。
- 引擎在编辑期间冻结身份投影，确认后裁切窗口并发布当前真实时钟。失败清理身份、报告安全错误和停止，不能据插件夹取后的currentIndex猜测当前条目。后续追加继续用绝对尾部，截尾转换为窗口内原生索引。
- 迟到旧大索引如果已超出新窗口会安全失败而非关联错误曲目。该防护并不取代真机事件时序验收；本轮不宣称所有原生时序无中断。
