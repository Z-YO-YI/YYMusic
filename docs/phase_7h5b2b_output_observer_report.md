# Phase 7H5B2b：输出观察协调层

## 范围与实现

遵循主指令第26节：输出观察不等于设备切换；系统默认输出不冒充播放器实际路由。新增独立AudioOutputController，借用AudioOutputGateway，不持久化设备名称、不修改播放状态、不启动设置或关闭借用的Gateway。

首次读取前订阅状态；initialize幂等，refresh先于initialize也只初始化一次。在途刷新突发合并为一个后续读取，读取串行；新请求到来时不发布旧读取返回值，新流事件/流错误使更早读取失效。流事件仍代表Gateway主动观察，不承诺其时间戳顺序。读取失败且无更新事件时清空旧输出，重复快照不重复通知。无未经验证的设备选择列表。

close同步撤销新工作并清空暂存名称，异步取消订阅、排空已接受读取；支持通知期间重入关闭。Gateway由未来根所有者在协调层关闭后释放。本阶段不绑定DependencyGraph、Presenter、Widget或前台生命周期；refresh仅准备接口，不能宣称返回设置已自动刷新。系统设置启动仍由既有Gateway提供，不能从观察器启动结果推断路由。
