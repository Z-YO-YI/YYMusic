# Phase 6C — 本地目录搜索与搜索历史

2026-09-05，`codex/catalog-search-data`，从已fetch/pull的`62b8a7c`独立分支开始。
ZIP、主指令、App.tsx与基础HTML四项指纹均匹配。按主指令17.2/22和Phase6顺序继续Search。
本批只交付数据合同与真实SQLite查询，不把参考HTML的内存catalog过滤当正式实现。

- 独立CatalogSearchRepository合同，正式DriftLibraryRepository实现，复用既有实体映射。
  歌曲/专辑/艺人分别稳定分页，按来源类型/来源ID过滤；字段包含标题、关联艺人和公开来源名称。
  分页CTE先限定实体，再同一只读语句连接艺人，避免分页切断多艺人、跨查询版本混合或开启写事务。
- 搜索值参数绑定，百分号/下划线/引号作为字面文本；空白查询不读整库。大小写规则明确为
  SQLite内建ASCII折叠，中文按字面子串匹配；不声称拼音、Unicode全文检索或FTS性能已实现。
- 可取消请求：派发前与每次异步读/映射后检查，不交付过期页；不宣称已经中断正在运行的SQLite语句。
- 搜索历史复用v2既有search_history表，最近20项稳定顺序、同查询/来源重复提交更新、原子裁剪、
  明确清除；查询本身不自动保存历史，不访问网络/媒体、不写入搜索结果或Fixture曲库。
- 测试覆盖中文/大小写/特殊字符、关联去重、完整来源身份、分页边界、取消、查询数、错误脱敏、
  持久文件重开、历史上限/并发/回滚及清除不影响曲库；再跑全量回归和双端CI。

不改Schema/依赖/权限/根播放器或现有UI。三端Search页面、防抖/Enter动作和根数据接线下一批做；
多来源REST并行仍按后续来源阶段接入，本地持久REST引用不等同于实时在线搜索。
