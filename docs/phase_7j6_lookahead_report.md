## 实现

- AudioSequenceAppend复制非空、entryId唯一的瞬时输入；沿用同一批次身份，从预期尾部索引继续编号，不保存地址到持久化状态。
- JustAudioEngine在唯一命令队列复核完整尾部、重复entry及headers能力。原生后端校验预期列表长度，使用addAudioSources追加，不重新load/play；completed拒绝追加，不能用追加隐式重播。
- 追加Future完成之前即可收到新索引，因此引擎与根先安装身份映射。追加失败清除身份并请求停止，异常索引不返回成功，插件错误转换为固定安全失败。
- 根起始最多加载三项，原生切曲后逐项补足两项前瞻。解析在根命令队列之外，提交追加回到根队列并复核绑定、策略版本、完整条目和尾部。每绑定最多一项解析任务；当前项推进后可继续补足，不并发解析整个队列。
- 解析失败停止本批补充，实际到期时仍使用既有普通推进和失败记录。继续/重复/随机/睡眠边界撤销后不能迟到追加；关闭先冻结接收，再排空已登记任务，不制造晚到UI/播放。
- 收到合法下一索引时立即撤销旧完成任务的session许可，避免存储等待期间仍推进旧曲。元数据仍在队列保存成功后发布，不提前改当前曲目。
