## 串行、撤销与关闭

- 根在首次淡出前锁定_userVolume，即使用户未调音量也不会让滑块跟随临时振幅。gain不是用户值；每次真正进入原命令队列时重验睡眠generation、runner身份及entry。
- 等待间隔不占命令队列。有效用户调音量、暂停、恢复播放、seek、上一首/下一首、重载/切曲、停止/清空撤销淡出；无效音量和明确被撤销的seek/play许可不撤销。新睡眠设置同步撤销旧runner，旧完成结果不覆盖新状态。
- 播放/重载前恢复振幅；暂停和停止先完成用户动作，再在finally恢复。用户新音量成功后清除临时振幅标记，旧恢复不会把旧音量写回。旧runner不能覆盖新runner持有的振幅。
- 根关闭先取消睡眠，等待已接受命令与全部runner作业，再由Graph释放借用引擎。只允许私有恢复调用使用allowClosed清理通道；不在正在执行的串行命令内await runner.close，避免恢复排队在自身之后而死锁。
- 写入失败也尝试恢复；恢复失败保存在根并由close返回安全DomainFailure。恢复的音量事件不能冒充播放失败已恢复，保留此前error。没有自动播放或失败重试伪成功。
